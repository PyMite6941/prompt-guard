Use Prompt Guard

Prompt Guard uses local pattern checks to identify common PII and prompt-injection phrases. Pattern checks are best-effort; they can miss unfamiliar formats and should be one layer of your application's security controls.

Command-line usage

prompt-guard examples/clean.txt
prompt-guard examples/leak.txt
prompt-guard examples/leak.txt --ignore=email,creditCard

The CLI accepts a file path or directory and an optional set of flags:

FlagDescription
--ignore=cat1,cat2Skip comma-separated categories
--jsonOutput machine-readable JSON results
--sarifOutput SARIF 2.1.0 log for code-scanning tools
--partial-redactionShow last 4 characters instead of full redaction
--config=pathLoad configuration from a .promptguardrc file
--tui / -tLaunch the terminal user interface

Supported ignore names: email, creditCard, apiKey, githubToken, awsSecretKey, databaseUrl, jwtToken, stripeKey, sshPrivateKey, ipAddress, phoneNumber, ssn, prompt_injection. Ignored matches are neither reported nor redacted.

Scan TypeScript text

import { scanText } from '@ai-clyde/promptguard';

const result = scanText(userPrompt);
if (!result.isSafe) {
  console.log(result.matches);
  // Block the request or review result.sanitizedText.
}
  • isSafe is true only when no enabled check matched.
  • matches contains each detected category, its matched value, and severity.
  • sanitizedText replaces detected PII with redaction markers.

Injection phrases are reported but left unchanged in sanitizedText. Do not treat the sanitized output as safe to send if the prompt was flagged for injection.

Severity levels

Every match is assigned a severity:

SeverityExamples
criticalCredit cards, API keys, GitHub tokens, AWS keys, DB URLs, Stripe keys, SSH keys, prompt injection
highSSNs, JWT tokens, system-prompt phrases
mediumEmails, phone numbers
lowSocial handles, IP addresses

Guard an OpenAI request

import { callAIGuarded } from '@ai-clyde/promptguard';

const answer = await callAIGuarded(userPrompt, {
  autoSanitize: true,
});

Set OPENAI_API_KEY in the environment before importing the AI helper. With autoSanitize: true, PII is redacted before the OpenAI call. Detected prompt injection always throws and is never sent, even when auto-sanitization is enabled. Without auto-sanitization, any detected PII or injection blocks the call.

The helper sends prompts that pass the configured checks to OpenAI. The standalone scanText function itself performs no network requests.

Configuration file (.promptguardrc)

Create a .promptguardrc in your project root:

{
  "ignore": ["ipAddress", "phoneNumber"],
  "minSeverity": "high",
  "partialRedaction": true,
  "customPatterns": {
    "internalTicket": {
      "pattern": "\\bTKT-\\d{6}\\b",
      "severity": "low"
    }
  }
}

Use --config=path to point to a custom config file. Options passed to scanText() or CLI flags take precedence over the config file.

See the setup guide to install and link the CLI locally.
