Set up Prompt Guard

Prompt Guard is a TypeScript package with a command-line tool. The scoped npm package is not published yet, so use the repository setup below until npm installation is available.

Install from source

git clone https://github.com/PyMite6941/prompt-guard.git
cd prompt-guard
npm install
npm run build

Link and run the CLI

Link the local package to make its prompt-guard executable available on your PATH:

npm link
prompt-guard examples/clean.txt
prompt-guard examples/leak.txt

When a file contains a detected issue, the command prints matches and a PII-redacted preview, then exits with status 1. Clean input exits with status 0.

Run the checks

npm test
npm run build

Install from npm when published

The @ai-clyde/promptguard package is not currently available from npm. After its first publication, install it with npm install @ai-clyde/promptguard and invoke the CLI with npx @ai-clyde/promptguard <file>.

Continue to the usage guide for detection options, TypeScript examples, and guarded OpenAI calls.
